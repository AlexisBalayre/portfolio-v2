# Hook catalog

Hooks are deterministic shell scripts wired in [`settings.json`](../settings.json) that run on
lifecycle events: zero LLM cost, zero context, no hallucination. You never invoke them; they
fire automatically. Exit code `2` blocks the operation, `0` allows it.

All hooks that need the toolchain load Node 20 via nvm from `.nvmrc` and call
`node_modules/.bin` directly, so they work even when the shell's default Node is older or
`yarn` is not on the path.

| Hook | Fires on | What it does |
| :--- | :------- | :----------- |
| `quality-checks.sh` | `Stop` | When `.ts/.tsx` files are dirty: Prettier `--write` + `next lint --fix` on the dirty files, then Prettier `--check`, `next lint --max-warnings=0`, and a whole-repo `tsc --noEmit`. Blocks (exit 2) on any failure. No-ops when no TS changed. |
| `convention-spot-check.sh` | `Stop` | Advisory scan of changed files: content JSON validity and required fields, logo files that exist, project image hosts present in `remotePatterns`, tech tiers, `<img>` instead of `next/image`, new `dangerouslySetInnerHTML`, `target="_blank"` without `rel`, leftover `console.log`, hardcoded site URL, and a reminder to sync `public/llms.txt` when data changed. Always advisory (exit 0). |
| `comment-pruner.sh` | `Stop` | When the session added net-new comments (hashed against a memo of already-adjudicated ones): exits 2 so the main loop dispatches the `comment-pruner` subagent over the touched files, then seals the memo. |
| `git-safety.sh` | `PreToolUse(Bash)` | Blocks recursive force-deletes, force pushes, hard resets, branch creation on the trunk, and pushes to the trunk. Trunk name from `.env` `GIT_TRUNK` (default `main`). Note: it matches the whole command text, so a heredoc that *quotes* one of those commands is blocked too; write such docs with the Write tool. |
| `protect-generated.sh` | `PreToolUse(Edit\|Write)` | Blocks edits to `public/sitemap*.xml`, `public/robots.txt` (regenerated by `next-sitemap` on build), `next-env.d.ts`, `.next/**`, `tsconfig.tsbuildinfo`, and `yarn.lock`. |
| `validate-file-naming.sh` | `PreToolUse(Write)` | Blocks new `.ts/.tsx` files that break the naming convention: reserved names under `app/`, PascalCase components, `use*` hooks, camelCase `lib/`. |
| `pre-compact-preserve.sh` | `PreCompact` | Injects must-preserve context (current branch + worktree path, modified files, check results) so it survives compaction. |

**Configure / disable:** edit the entry under `hooks` in `settings.json`. Scripts must stay
executable (`chmod +x`). To add a hook, see [`.claude/README.md`](../README.md) ("New hook").
