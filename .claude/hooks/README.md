# Hook catalog

Hooks are deterministic shell scripts wired in [`settings.json`](../settings.json) that run on
lifecycle events: zero LLM cost, zero context, no hallucination. You never invoke them; they
fire automatically. Exit code `2` blocks the operation, `0` allows it.

Stack commands, generated paths, and the trunk name come from the project profile
[`.claude/project.env`](../project.env); an empty key turns its check off. Hooks that need the
toolchain load Node 20 via nvm from `.nvmrc` and call `node_modules/.bin` directly, so they
work even when the shell's default Node is older or `yarn` is not on the path.

| Hook | Fires on | What it does |
| :--- | :------- | :----------- |
| `quality-checks.sh` | `Stop` | When `SOURCE_EXTENSIONS` files (`.ts/.tsx`) are dirty: `FORMAT_FIX_CMD` (ESLint `--fix`, which runs Prettier through `plugin:prettier/recommended`) then `LINT_CMD` (ESLint `--max-warnings=0`) on the dirty files, then `TYPECHECK_CMD` (whole-repo `tsc --noEmit`). Blocks (exit 2) on any failure. No-ops when no TS changed. |
| `convention-spot-check.sh` | `Stop` | Scan of the session's changed and untracked files. Grep checks come from [`spot-checks.tsv`](../spot-checks.tsv) (`<img>` instead of `next/image`, leftover `console.log`, hardcoded site URL); the script adds the jq and cross-file checks: content JSON validity and required fields, logo files that exist, project image hosts present in `remotePatterns`, tech tiers, new `dangerouslySetInnerHTML`, `target="_blank"` without `rel`, and `public/llms.txt` drift when data changed. Blocks once (exit 2) so findings actually reach the model (exit-0 output never does), then stays silent on the `stop_hook_active` re-run so a heuristic misfire cannot loop. |
| `comment-pruner.sh` | `Stop` | When the session added net-new comments (hashed against a memo of already-adjudicated ones): exits 2 so the main loop dispatches the `comment-pruner` subagent over the touched files, then seals the memo. |
| `git-safety.sh` | `PreToolUse(Bash)` | Blocks recursive force-deletes, force pushes, hard resets, branch creation on the trunk, and pushes to the trunk. Trunk name from `GIT_TRUNK` in `.claude/project.env` (default `main`). Note: it matches the whole command text, so a heredoc that *quotes* one of those commands is blocked too; write such docs with the Write tool. |
| `protect-generated.sh` | `PreToolUse(Edit\|Write)` | Blocks edits to `public/sitemap*.xml`, `public/robots.txt` (regenerated by `next-sitemap` on build), `next-env.d.ts`, `.next/**`, `tsconfig.tsbuildinfo`, and `yarn.lock`, each with a message naming what regenerates it. Keep the list in step with `GENERATED_PATHS_REGEX`, which `comment-pruner.sh` uses to skip the same paths. |
| `validate-file-naming.sh` | `PreToolUse(Write)` | Blocks new `.ts/.tsx` files that break the naming convention: reserved names under `app/`, PascalCase components, `use*` hooks, camelCase `lib/`. Overwriting an existing file passes, and so do paths outside `$CLAUDE_PROJECT_DIR`, so a session reaching into a sibling repo is not held to these rules. |
| `pre-compact-preserve.sh` | `PreCompact` | Injects must-preserve context (current branch + worktree path, modified files, check results) so it survives compaction. |

**Configure / disable:** edit the entry under `hooks` in `settings.json`. Scripts must stay
executable (`chmod +x`). To add a hook, see [`.claude/README.md`](../README.md) ("New hook").
